# S00 — Toolchain and the register window

> [!NOTE]
> Assembly, section 00. Index: [Assembly Sections](../Assembly%20Sections.md) · questions: [Assembly Question Bank](../Assembly%20Question%20Bank.md) · teaching notes: [Assembly Playbook](../Assembly%20Playbook.md).

**One idea to land:** the only way to learn this subject is to watch the machine change. Setup is not admin, it is the first lesson.

**What I do:** everyone assembles, links, and runs one 5-line program **on their own machine** before leaving. Then I show the four windows they will live in: source, registers, flags, memory dump.

**Live demo:** step a three-instruction program and stop after each, asking "what changed?" before revealing it. Establishes the habit for the term.

**Their turn:** change one immediate value, re-run, predict the register before stepping.

**Close:** "You will never debug this subject by reading. You will debug it by stepping."
