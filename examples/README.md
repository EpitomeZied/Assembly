# Assembly examples

- [AddSub.asm](AddSub.asm) — adds and subtracts immediate values in `EAX`, then displays registers.
- [AddSub2.asm](AddSub2.asm) — uses DWORD variables and stores the result in `finalVal`.

These examples use 32-bit MASM syntax and `Irvine32.inc`. Build them in a Windows x86 MASM project with the Irvine32 include and library paths configured. The Irvine32 dependencies are not bundled here.

Existing `.exe` and `.obj` files remain available locally and are ignored by Git. Track the `.asm` sources when sharing the examples.
